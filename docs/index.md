# Clasp Support

Clasp is a local-first Markdown notes app for Apple silicon Macs running macOS 14 or later. Paper LLC publishes Clasp.

## Contact support

Email [hello@paper.ai](mailto:hello@paper.ai) for app issues, general feedback, or feature requests.

You can also [open a public GitHub issue](https://github.com/RobertBMoore/clasp/issues/new) or review [existing issues](https://github.com/RobertBMoore/clasp/issues). GitHub Issues are public. Remove private information from screenshots and examples, and never post note bodies, Vault files, recovery keys, credentials, clipboard contents, or other sensitive data.

For the quickest diagnosis, include:

- your Clasp version and build number;
- your macOS version and Mac model;
- the steps that led to the problem;
- what you expected and what happened instead; and
- a screenshot only if it contains no private information.

## Security reports

Do not report a suspected vulnerability in a public issue. Use GitHub's [private vulnerability reporting form](https://github.com/RobertBMoore/clasp/security/advisories/new), or email [hello@paper.ai](mailto:hello@paper.ai) with the subject `Clasp security report` if you cannot use GitHub. Do not attach a Vault export together with its recovery key.

## Common help

- **Quick Capture:** press `Option-Space`. If another app owns that shortcut, use `Control-Option-Command-Space`.
- **Capture copied content:** press `Control-Option-Command-C` for a regular Inbox note or `Control-Option-Command-V` for a secure Vault note.
- **Capture selected content from the Mac App Store build:** right-click the selection and choose **Services › Create Note in Clasp** or **Create Secure Note in Clasp**. macOS may require enabling these once under **System Settings › Keyboard › Keyboard Shortcuts › Services › Text**.
- **More help:** open **Help › Clasp Help** inside the app for shortcuts, data locations, Service setup, and encrypted Vault export and import.

Regular notes and their attachments are plaintext files on the Mac. Vault notes are encrypted at rest, but Clasp cannot protect an unlocked Mac from malware or a person controlling that session. Credentials and recovery codes are best kept in a dedicated password manager.

Read the [Clasp Privacy Policy](privacy.html) or the repository's [security documentation](https://github.com/RobertBMoore/clasp/blob/main/SECURITY.md).
